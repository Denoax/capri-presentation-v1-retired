# Retired CAPRI presentation snapshot

This repository is an archived historical export. Maintained development and the V3 presentation are in **[Denoax/capri](https://github.com/Denoax/capri)**, the original implementation repository. That repository is private and requires access.

This snapshot preserves the earlier public presentation and its Git history; it is not the current implementation or a second maintained product. The old graphics have been superseded. Current qualification and public-release decisions belong to the maintained repository.
