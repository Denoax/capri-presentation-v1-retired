# Bring a repro

Use the [inherited contribution rules](../CONTRIBUTING.md) and [offline setup](QUICKSTART.md). A useful patch names its source commit, observed behavior, expected behavior, reproduction and actual checks, including failed or unavailable ones.

Keep changes narrow. Do not weaken namespace checks or fabricate runtime evidence. Runtime work needs independent review and the source-bound human decision. Presentation changes must preserve source/asset provenance and readable static alternatives; follow the [shipped reference policy](../controller/policies/reference-led-design.md).

[Open a pull request](https://github.com/Denoax/capri/pulls) for a concrete change. The public issue tracker is disabled. Security reports use an existing trusted private channel to the owner, as described in [SECURITY.md](../SECURITY.md).

This preview follows a fixed implementation snapshot. Changes here do not synchronize the private development checkout or authorize its integration. Read [license status](LICENSE_STATUS.md) before proposing third-party code or media.
